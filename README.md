# Urgence Plomberie Bruxelles (Association ASBL / VZW)
> **Helping you find plumbing assistance across Belgium**

Official website for the non-profit association **Urgence Plomberie Bruxelles**, dedicated to connecting households and individuals with verified, registered plumbing professionals across Brussels and throughout Belgium.

---

## 🌟 Key Features

1. **HOME Section**
   - **Hero Headline**: *"Need a plumber? We're here to help."*
   - **Subtitle**: *"Finding a reliable plumber shouldn't be difficult. Our association helps individuals and families connect with plumbing professionals in their area."*
   - **Main CTA**: *Find a Plumber*
   - **Secondary CTA**: *Join Our Association*
   - **6 Specialized Services**:
     - Leak detection and repairs
     - Blocked pipes and drains
     - Bathroom and kitchen installations
     - Water heaters and boilers
     - Heating and plumbing maintenance
     - General plumbing repairs
   - **How does it work?**: 3-step transparent matching workflow.
   - **Our mission**: Promoting trust, transparency, and quality service across Belgium.
   - **For plumbing professionals teaser**: Invitation to join the association network.

2. **FIND A PLUMBER (Interactive Matching System)**
   - **Headline**: *"Find the right plumbing assistance near you."*
   - **Subtitle**: *"Tell us about your needs and location. We'll help you find a plumbing professional."*
   - Comprehensive form:
     - Full name
     - Phone number
     - Email address
     - City / Postcode (with Brussels 19 Communes quick selectors)
     - Type of plumbing problem (auto-fillable from service cards)
     - Urgency level (Emergency 1-2h, Today, Within 48h, Estimate)
     - Problem description
     - Preferred contact method (Phone, WhatsApp, Email, SMS)
     - Photo upload (with drag & drop and instant image preview)
   - **Submission Confirmation**:
     - *"Thank you for contacting us! We have received your request. Our team will review your information and contact you about the next steps."*
     - Generates reference ticket number (`#UPB-2026-XXXX`).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Development Server
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your web browser.

### Production Build
```bash
npm run build
```
The optimized static output is generated in the `dist/` directory, ready to deploy to Netlify, Vercel, Cloudflare Pages, or any static host.
